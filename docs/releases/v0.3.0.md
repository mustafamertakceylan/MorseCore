# MorseCore 0.3.0

## Türkçe

Windows masaüstü önizlemesi: dönüştürücü, toplu dosya işlemleri, Morse sesi/WAV, alıştırma, alfabe ve Ayarlar. Türkçe, İngilizce, Almanca, Rusça ve Arapça arayüz; Arapçada sağ menü ve soldan sağa Morse alanları. RAW zeytin/krem temaları, ortalanmış logo ve basma–taşıma–bırakma davranışına sahip özel üst çubuk.

- **MorseCore-0.3.0-Windows-x64-Desktop.zip**: ZIP'in tamamını açıp `MorseCore.Desktop.exe` çalıştırın. .NET/Windows App SDK çalışma zamanı dahildir. İmzasız önizlemedir; MSIX kurulum/güncellemesi henüz sunulmaz.
- **MorseCore-0.3.0-Windows-AMD64.zip**: konsol uygulaması, C23 native DLL, C API başlığı ve belgeler.
- **SHA256SUMS**: indirdiğiniz dosyanın bütünlük denetimi için.

Seslendirme isteğe bağlıdır. Python 3.11–3.13 ile `setup-speech.cmd` bir kez internet üzerinden motorları/modelleri kurar; sonrasında üretim yereldir. Ağırlıklar ve Python ses ortamı ZIP'lere dahil değildir. Türkçede **EMA Lightning 1.1.2** ve **Antalia Mini 1.0.1**, diğer dört dilde altı Piper sesi desteklenir. Ses ortamını farklı bir bilgisayara kopyalamak yerine orada yeniden kurun.

**Canberk Aslan'a (EMA Lightning) ve PatientDesk AI ekibine (Antalia-2 Mini) teşekkür ederiz.** Apache-2.0 lisansları ve Antalia'nın özgün NOTICE dosyası korunmuştur. Piper, ses modelleri, fontlar ve çalışma zamanları kendi lisanslarını korur; masaüstü ZIP'inde bağımlılık bildirimleri bulunur. Kareem sesinin veri lisansı netleşmeden model ağırlıkları MorseCore tarafından yeniden dağıtılmaz.

Yerel doğrulama: native/.NET testleri; beş dilde UI ve gerçek Windows fare girdisiyle iki sürükleme, bırakınca durma, tek tıklamayla hareketin kilitlenmemesi ve logo ortalama. GitHub Actions, yayın öncesinde Windows/Linux derleme ve testlerini ayrıca çalıştırır. Fiziksel ses çıkışı, farklı ekran/DPI cihazları, imzalı MSIX güncellemesi ve macOS/Linux masaüstü sürümleri henüz doğrulanmadı.

## English

Windows desktop preview with conversion, file batches, Morse audio/WAV, practice, alphabet and Settings. Turkish, English, German, Russian and Arabic UI; Arabic mirrors navigation while Morse fields stay left to right. RAW olive/cream themes, centered branding and a custom title bar with native press–drag–release behavior.

- **MorseCore-0.3.0-Windows-x64-Desktop.zip**: extract the entire ZIP and run `MorseCore.Desktop.exe`. .NET/Windows App SDK runtime files are included. This is an unsigned preview; MSIX installation/updates are not provided yet.
- **MorseCore-0.3.0-Windows-AMD64.zip**: console application, C23 native DLL, C API header and documentation.
- **SHA256SUMS**: integrity checksums for the downloads.

Speech is optional. With Python 3.11–3.13, run `setup-speech.cmd` once online; synthesis then stays local. Weights and the Python speech environment are not included in either ZIP. Turkish supports **EMA Lightning 1.1.2** and **Antalia Mini 1.0.1**; the other four languages use six Piper voices. Reinstall the speech environment on another computer instead of copying its virtual environment.

**Thank you to Canberk Aslan (EMA Lightning) and PatientDesk AI (Antalia-2 Mini).** Their Apache-2.0 license texts and Antalia's original NOTICE are preserved. Piper, voices, fonts and runtimes retain their own licenses; the desktop ZIP includes dependency notices. MorseCore does not redistribute Kareem weights while its dataset license needs clarification.

Local validation covers native/.NET tests, five-language UI, and real Windows mouse input for repeated dragging, release, single-click behavior and centered branding. GitHub Actions independently runs Windows/Linux build and test gates before publication. Physical speaker output, other monitor/DPI setups, signed MSIX updates and macOS/Linux desktop editions remain unverified.
