# MorseCore v0.7.4

### English

- A rounded green taskbar icon replaces the cream square.
- Opening MorseCore again brings back the existing window, including when minimized. The app and its installed shortcuts share a Windows taskbar identity.
- The GitHub description and topics now explain the app in simpler language.

Run **MorseCore-0.7.4-Windows-x64-Setup.exe** to install or upgrade. Existing users can check for updates in Settings. The portable ZIP and `SHA256SUMS` are also available below.
