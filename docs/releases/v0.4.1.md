# MorseCore 0.4.1

## English

- Download and verify Windows updates from Settings, then confirm to open Setup and close MorseCore.
- Setup detects Python 3.11–3.13 x64. If missing, it offers the bundled official Python 3.13.16 installer; installation is optional and does not change PATH.
- Voice models remain optional, downloaded separately once. EMA Lightning and Antalia Mini power Turkish speech; original notices are included.

## Türkçe

- Ayarlardan Windows güncellemesini indirip doğrulayın; onayınızla Setup açılır ve MorseCore kapanır.
- Setup Python 3.11–3.13 x64 arar. Eksikse paketindeki resmî Python 3.13.16 kurucusunu isteğe bağlı sunar; PATH değişmez.
- Ses modelleri isteğe bağlıdır ve ayrıca bir kez indirilir. Türkçe seslendirme EMA Lightning ve Antalia Mini kullanır; özgün bildirimler pakettedir.

Setup is unsigned / Setup imzasızdır. Windows x64 only / Yalnızca Windows x64.
