# MorseCore v0.7.3

## English

- Fixed the outer workspace touching the title bar and sidebar. The workspace now has space on all four sides, with navigation and page headings kept aligned.
- The same spacing applies to light/dark themes, expanded/collapsed navigation and Arabic's mirrored layout.

Install or upgrade with **MorseCore-0.7.3-Windows-x64-Setup.exe**, or extract **MorseCore-0.7.3-Windows-x64-Desktop.zip**. Existing users can check for updates in Settings. Download checksums are in `SHA256SUMS`.

- Aynı boşluklar açık/koyu temada, dar/geniş menüde ve Arapçanın aynalanmış düzeninde uygulanır.
