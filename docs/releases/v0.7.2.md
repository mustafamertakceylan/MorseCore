# MorseCore v0.7.2

## English

- Loading is now a full-window welcome screen with no title bar or reserved header space. The bar appears with the main screen.
- Dark mode separates the workspace, cards, input fields and results with clearer green tones and borders. Light-mode colors and spacing are unchanged.

Install or upgrade with **MorseCore-0.7.2-Windows-x64-Setup.exe**, or extract **MorseCore-0.7.2-Windows-x64-Desktop.zip**. Existing users can check for updates in Settings. Download checksums are in `SHA256SUMS`.

## Türkçe

- Açılış artık üst çubuk veya ayrılmış başlık boşluğu olmayan, tüm pencereyi kullanan bir karşılama ekranıdır. Çubuk ana ekranla birlikte görünür.
- Karanlık temada çalışma zemini, kartlar, giriş alanları ve sonuçlar daha belirgin yeşil tonları ve kenarlıklarla ayrılır. Açık tema renkleri ve aralıkları korunur.

Kurmak veya yükseltmek için **MorseCore-0.7.2-Windows-x64-Setup.exe** dosyasını çalıştır; taşınabilir seçenek **MorseCore-0.7.2-Windows-x64-Desktop.zip**. Ayarlar üzerinden güncelleme kontrol edilebilir. Dosya özetleri `SHA256SUMS` içindedir.
