# MorseCore 0.4.0

## Türkçe

MorseCore artık masaüstü uygulamasına odaklanıyor. Eski konsol menüsü, komut satırı uygulaması ve konsol ZIP'i kaldırıldı. C23 motoru, ABI v1 DLL, .NET bağlantıları ve masaüstündeki dönüşüm, dosya, ses ve alıştırma özellikleri korunuyor.

- [Windows x64 Setup.exe](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/MorseCore-0.4.0-Windows-x64-Setup.exe)
- [Windows x64 taşınabilir ZIP](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/MorseCore-0.4.0-Windows-x64-Desktop.zip)
- [SHA256SUMS](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/SHA256SUMS)

Setup mevcut kullanıcıya kurulur; beş dil, Başlat menüsü kısayolları ve Windows'tan kaldırma desteği sunar. Taşınabilir ZIP'i kullanıyorsanız tüm dosyaları açıp `MorseCore.Desktop.exe` dosyasını çalıştırın. Paketler imzasızdır; MSIX ve güvenilir imza henüz sunulmaz.

Seslendirme isteğe bağlıdır. Python 3.11–3.13 ve ilk kurulumda internet gerekir; modeller ayrıca indirilir, sonrasında ses üretimi çevrimdışıdır. Setup ile ses paketi `%LOCALAPPDATA%\MorseCore\Speech` altında saklanır. Önceden kurulmuş bir taşınabilir ses paketi varsa Ayarlar'dan o klasörü seçebilirsiniz.

**Canberk Aslan'a EMA Lightning**, **PatientDesk AI ekibine Antalia-2 Mini** için teşekkür ederiz. Özgün lisanslar, Antalia NOTICE ve çalışma zamanı lisansları paketlere dahildir. Masaüstü tercihleri ve kullanıcı dosyaları korunur. Eski konsolun `config/` ve `data/` dosyaları artık kullanılmaz. Önceki `v0.3.0` sürümü arşiv olarak erişilebilir kalır.

## English

MorseCore now focuses on the desktop application. The legacy console menu, command-line app and console ZIP have been removed. The C23 engine, ABI v1 DLL, .NET bindings, and desktop conversion, files, audio and practice features remain available.

- [Windows x64 Setup.exe](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/MorseCore-0.4.0-Windows-x64-Setup.exe)
- [Windows x64 portable ZIP](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/MorseCore-0.4.0-Windows-x64-Desktop.zip)
- [SHA256SUMS](https://github.com/mustafamertakceylan/MorseCore/releases/download/v0.4.0/SHA256SUMS)

Setup installs for the current user and provides five wizard languages, Start menu shortcuts and Windows uninstall support. For the portable ZIP, extract every file and run `MorseCore.Desktop.exe`. Packages are unsigned; MSIX and trusted signing are not available yet.

Speech is optional. Python 3.11–3.13 and internet are required once for setup; models download separately, then synthesis works offline. Setup's speech pack lives in `%LOCALAPPDATA%\MorseCore\Speech`. An existing portable speech pack can be selected in Settings.

Thank you to **Canberk Aslan for EMA Lightning** and **PatientDesk AI for Antalia-2 Mini**. Original licenses, Antalia's NOTICE and runtime notices are included. Desktop preferences and user-created files are retained. Legacy console `config/` and `data/` files are no longer used. The previous `v0.3.0` release remains available as an archive.
