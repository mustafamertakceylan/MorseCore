# MorseCore v0.5.0

## English

- Added saved station profiles, call-sign recognition, Turkish call areas and dated country references. Includes CW preparation and local QSO logs; this version does not control radio hardware or transmit RF.
- Added CQ, reply, RST and closing templates, joined prosigns, Morse/WAV preview, and separate practice/contact CSV and ADIF exports.
- Grouped the alphabet, exercises and radio glossary under Learning. Added six exercise types, mistake review and phonetics; playback and offline speech now live on Audio.
- Refined the RAW-inspired sidebar with a straight selection indicator, preserving rounded rows, five languages and Arabic mirroring.
- Added verified in-app update downloads and confirmation before Setup. Setup detects compatible Python and offers the bundled official installer with consent; voice setup works without PATH changes.

Country references cover selected ranges only. Russian frequency/power matching is disabled because the current primary annex was inaccessible. See the [country guide](https://github.com/mustafamertakceylan/MorseCore/blob/v0.5.0/docs/amateur-radio.md) for sources, dates and exclusions.

## Türkçe

- Kayıtlı istasyonlar, çağrı işareti tanıma, Türkiye çağrı bölgeleri ve tarihli ülke kaynakları eklendi. CW hazırlığı ve yerel QSO günlüğü bulunur; bu sürüm telsiz donanımını yönetmez veya RF yayını yapmaz.
- CQ, yanıt, RST ve kapanış şablonları; bitişik prosedür işaretleri, Morse/WAV önizlemesi ve ayrı eğitim/görüşme CSV–ADIF aktarımları eklendi.
- Alfabe, alıştırmalar ve telsiz sözlüğü Eğitim altında toplandı. Altı alıştırma türü, yanlış tekrarı ve fonetik alfabe eklendi; çalma ve çevrimdışı seslendirme Ses sayfasına taşındı.
- RAW tarzı menüye düz seçim çizgisi eklendi; yuvarlak satırlar, beş dil ve Arapça yön düzeni korundu.
- Doğrulanan uygulama içi güncelleme indirmesi ve Setup öncesi onay eklendi. Setup uyumlu Python'ı algılar; resmî kurucuyu kullanıcı seçimiyle çalıştırır. Ses kurulumu PATH değişikliği istemez.

Ülke rehberleri seçili aralıkları kapsar. Güncel birincil eke erişilemediği için Rusya frekans/güç eşleştirmesi kapalıdır. Kaynaklar, tarihler ve kapsam [ülke rehberindedir](https://github.com/mustafamertakceylan/MorseCore/blob/v0.5.0/docs/amateur-radio.md).

## Downloads / İndir

Use **MorseCore-0.5.0-Windows-x64-Setup.exe** for installation, or extract **MorseCore-0.5.0-Windows-x64-Desktop.zip** and run `MorseCore.Desktop.exe`. Both target Windows x64. Checksums are in `SHA256SUMS`.

For the first upgrade from v0.4.0, download and run the new Setup. Verified in-app installation is included from this release onward.

Kurulum için **MorseCore-0.5.0-Windows-x64-Setup.exe** dosyasını çalıştırın. Taşınabilir kullanım için **MorseCore-0.5.0-Windows-x64-Desktop.zip** arşivini açıp `MorseCore.Desktop.exe` dosyasını başlatın. Dosya özetleri `SHA256SUMS` içindedir.

v0.4.0'dan ilk geçiş için yeni Setup'ı indirip çalıştırın. Doğrulanan uygulama içi kurulum bu sürümden sonraki güncellemelerde kullanılabilir.

The app and Windows App SDK runtimes are included. Setup can optionally install Python 3.13 if needed. Speech models download separately once, then run offline. Thank you to EMA Lightning, Antalia-2 Mini and Piper contributors. MorseCore uses Apache 2.0; components and models retain their own licences. The installer is unsigned. macOS/Linux desktop releases and signed MSIX remain pending.
